Roughio

Setup and quick start

- Node version: 18.x (use .nvmrc in repo root)
- CI: GitHub Actions (lint, type-check, build)

Development
- Install: npm ci
- Run dev: npm run dev
- Lint: npm run lint
- Type-check: npm run type-check
- Build: npm run build

Directory overview
- src/: source code
- supabase/: DB seeds and migrations
- next.config.mjs, tsconfig.json: configuration

Contributing
- Fork the repo, create a feature branch, open a PR.  Run npm run check before PRs.
